# Multi_Stage_FIR_Decimator_for_complex_IQ_data
A configurable multi-stage FIR decimator for complex I/Q data, implemented in VHDL for FPGA-based digital signal processing. The design cascades multiple FIR filter stages to support selectable decimation rates of 2×, 4×, 8×, and 16× while preserving the I/Q data structure.
